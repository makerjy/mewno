# Notion과 로컬 문서 정리

0.1.2의 전달 경로는 편집본 복사와 Markdown 저장입니다. 사용자가 Notion에 직접 붙여넣거나 파일을 가져올 수 있습니다. 앱은 토큰을 요청하거나 페이지를 생성하지 않습니다.

후속 로컬 LLM 기능은 강의·회의·인터뷰·일반 템플릿과 별도 문서 저장을 제공할 예정입니다. 원문 구간 ID와 시각을 인용하고, 재생성 시 이전 편집본을 보존하며, 출처가 불명확한 진술에는 검토 표시가 필요합니다.

이후 Notion 연동을 구현할 때는 연결 계정의 권한 범위와 대상 페이지, 보낼 문서의 미리보기를 먼저 표시합니다. 사용자가 확인한 문서만 전송하고 결과 링크 또는 실패 상태를 반환합니다. 개인용 토큰은 macOS Keychain에 보관하고 연결 해제 때 지웁니다. 배포용 공개 OAuth는 서버 측 비밀 관리 방식을 확정한 뒤 구현합니다. [Notion 공식 인증 가이드](https://developers.notion.com/docs/authorization)
