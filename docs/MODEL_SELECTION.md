# 모델 선택

src-tauri/models.json은 고정 Hugging Face 리비전의 다국어 Tiny, Base, Small 파일 이름·바이트 수·SHA-256·라이선스를 기록합니다. 설치 때 전용 임시 파일을 사용하며 해시와 길이가 일치할 때만 캐시에 반영합니다. 전사하기 직전에도 다시 검사합니다. 승인 화면에 용량을 표시하고 다운로드 중 실제 수신 바이트를 표시합니다.

| 모델 | 파일 크기 | 추천 조건 |
|---|---:|---|
| Tiny | 77,691,713 B | 속도 우선, 메모리 정보 미확인 또는 사용 가능 추정치 2 GiB 미만 |
| Base | 147,951,465 B | 균형 기본값, 사용 가능 추정치 2 GiB 이상 |
| Small | 487,601,967 B | 정확도 선호, 사용 가능 추정치 4 GiB 이상 |

이 기준은 앱의 보수적 선택 규칙입니다. 모델별 성능 측정값은 [시험 결과](TEST_REPORT.md)에 별도로 표시합니다. 추천 모델의 저장 공간이 부족하면 작은 후보를 검토합니다. 자동 선택은 설치된 추천 모델을 우선하며, 다른 설치 모델도 사용할 수 있습니다. 모든 모델은 수동 선택할 수 있습니다. 다운로드 때 파일 크기 외에 최소 16 MB의 여유를 확인합니다.

macOS 버전, CPU 모델과 코어 수, 총 메모리, GPU 이름, 현재 남은 디스크를 시스템에서 읽습니다. 사용 가능 메모리는 vm_stat의 free + inactive 페이지 추정치이며 OS의 메모리 압축 결과와 다를 수 있습니다. 전용 GPU 메모리는 미확인으로 표시합니다. 전사 설정에서 CPU만 사용할 수 있습니다.

설정한 분야와 사용자가 입력한 용어는 Whisper의 초기 프롬프트로 전달합니다. 인명, 수치, 전문 용어는 음성과 대조해 주세요. 사용 목적은 보존되며 문서 템플릿 연동은 후속 작업입니다.
