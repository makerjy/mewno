# 저장 위치와 네트워크

macOS의 기본 위치는 ~/Library/Application Support/app.mewno.desktop/입니다. mewno.sqlite3에 녹음 경로와 전사 내용·수정본·설정을, models/에 모델을, work/에 변환 중인 음원을 보관합니다. 완료·취소 시 작업 임시 폴더가 정리됩니다. 비정상 종료 후에는 다음 시작 때 work/를 정리합니다. 원본 녹음은 사용자가 선택한 위치에 둡니다.

현재 네트워크 기능은 사용자가 승인한 모델 다운로드입니다. 고정 리비전의 HTTPS 주소로 시스템 curl을 실행하며 반환된 파일은 SHA-256으로 검사합니다. 앱에는 원격 AI, 분석 수집기와 Notion 클라이언트가 없습니다. UI, 이미지, 글꼴은 앱 안에 있습니다. 오디오는 로컬 트랙만 읽도록 제한합니다.

내 기록에서 개별 기록을 삭제할 수 있습니다. 모델 삭제는 모델 관리에서 별도로 수행합니다. 삭제는 논리적 데이터 삭제이며 OS 백업·기존 내보내기·복사한 클립보드까지 지우지는 않습니다. SQLite·모델·임시 PCM 및 사용자가 저장한 Markdown은 앱 차원에서 암호화하지 않습니다. 디스크 보호는 운영체제 및 사용자 계정의 설정에 따릅니다.
